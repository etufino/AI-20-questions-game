# AI-20-questions-game
Interactive Python notebook and Hugging Face implementation for a “20 Questions” micro-lab to explore LLM stochasticity and context control.

Python materials accompanying the paper:Demystifying the oracle: A "20 Questions" game to foster AI ethics and literacy

This repository contains:
- a runnable **Google Colab / Jupyter notebook** implementing the core “20 Questions” activity,

## API key (Gemini)
This project **does not include any API key**.
To run it, you must provide your own **Gemini API key** at runtime, e.g. by setting:

- `GEMINI_API_KEY` (required)
- `CLASS_PASSWORD` (optional; only if you enable a classroom gate)
